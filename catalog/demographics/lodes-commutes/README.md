# LODES Commute Flows

Home→work commute flows touching the City of St. Louis, from the U.S. Census Bureau's LEHD Origin-Destination Employment Statistics (LODES) version 8, data year 2023 — every block-group pair where the home or the workplace (or both) is inside the city, with job counts by earnings band. LODES is the block-level jobs data behind the Bureau's OnTheMap tool; "Version 8 of LODES was enumerated by 2020 census blocks." Flows are aggregated from block→block pairs to block-group→block-group pairs (a block's block group is the first 12 characters of its geocode); `home_in_city` and `work_in_city` flag each end. Out-of-state residents who work in Missouri come from the LODES auxiliary file, so Illinois-to-St.-Louis commutes are included; St. Louis residents working outside Missouri are not, per LODES file structure. LEHD notes that "the data released by LEHD are based on tabulated and modeled administrative data, which are subject to error."
This is a tabular collection with no geometry: join `home_geoid` or `work_geoid` to the `acs-block-groups` or `lodes-jobs` collections (their `geoid` column) to map it. Unlike the city's own datasets in this catalog, this is **not** City of St. Louis data: it is federal administrative data published by the U.S. Census Bureau's Longitudinal Employer-Household Dynamics program. Explore it in the [St. Louis data browser](https://cholmes.github.io/stlouis-data-browser/#/demographics/lodes-commutes/collection.json).

## Schema

| Column | Type | Description |
|--------|------|-------------|
| home_geoid | string | 12-digit block group GEOID where the workers live. Joins acs-block-groups.geoid. |

## Processing Notes

Built from the LODES 8 Origin-Destination files for Missouri, 2023 (https://lehd.ces.census.gov/data/lodes/LODES8/mo/od/, main + auxiliary, job type JT00). The main file covers workers who live and work in Missouri; the auxiliary file adds workers living out of state with jobs in Missouri, so Illinois-to-St.-Louis commutes are included. Kept every block-to-block flow with either end in St. Louis city and aggregated to block-group pairs by GEOID prefix. St. Louis residents working outside Missouri are not covered, per the LODES file structure.

This collection is tabular (no geometry): join home_geoid or work_geoid to acs-block-groups to map it.
